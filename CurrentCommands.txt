==================================================
 SecureChat - Comandos rapidos (Windows PowerShell)
 Ejecutar todo desde la raiz del repo: SecureChat_Workshop\
==================================================

Estructura:
  srcAlice\   -> main.py, config.py, tcp_client.py, alice_handshake.py   (+ .venv y keys\ de Alice)
  srcBob\     -> main.py, config.py, tcp_server.py, bob_handshake.py     (+ .venv y keys\ de Bob)
  srcShared\  -> codigo comun (lo importan ambos main.py automaticamente)
  tests\      -> pruebas automaticas (pytest, 41 pruebas)
  DescripcionDelProtocolo\ -> documento .tex, referencias.bib e img\
  requirements.txt (raiz) -> lo usan ambos entornos virtuales

---------- (Solo una vez) Si PowerShell bloquea Activate.ps1 ----------
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned


==================================================
 BOB - Crear entorno virtual (solo una vez)
==================================================
py -3 -m venv srcBob\.venv
srcBob\.venv\Scripts\python.exe -m pip install --upgrade pip
srcBob\.venv\Scripts\python.exe -m pip install -r requirements.txt


==================================================
 ALICE - Crear entorno virtual (solo una vez)
==================================================
py -3 -m venv srcAlice\.venv
srcAlice\.venv\Scripts\python.exe -m pip install --upgrade pip
srcAlice\.venv\Scripts\python.exe -m pip install -r requirements.txt


==================================================
 EJECUTAR (Terminal 1 = Bob primero, Terminal 2 = Alice despues)
==================================================

--- Terminal 1: BOB ---
cd srcBob
.\.venv\Scripts\Activate.ps1
python main.py
   -> Menu: opcion 1 (Esperar conexion de Alice) + frase de paso

--- Terminal 2: ALICE ---
cd srcAlice
.\.venv\Scripts\Activate.ps1
python main.py
   -> Menu: opcion 1 (Conectarse con Bob) + frase de paso

Antes del primer chat (solo una vez por par de llaves):
   opcion 2 en ambos (generar llaves) -> opcion 3 (ver huella) -> opcion 4 (registrar la huella del otro)

Dentro del chat:
   escribir texto + Enter            -> enviar mensaje (cifrado AES-256-GCM)
   /ayuda                            -> lista de comandos
   /detalle                          -> mostrar / ocultar nonce, ciphertext y tag
   /estado                           -> contadores y numeros de secuencia
   /alterar [ct|tag|nonce|tipo]      -> PRUEBA Paso 6: el proximo mensaje sale con 1 byte alterado
   /salir                            -> terminar la sesion (despedida cifrada; ambos vuelven al menu)
   Ctrl+C                            -> tambien cierra la sesion de forma ordenada
